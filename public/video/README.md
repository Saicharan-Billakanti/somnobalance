# Hero video drop-in

Drop the final cinematic loop here and the homepage hero switches from the
flip-card fallback to the video automatically (see `heroVideoAvailable()` in
`src/app/[lang]/page.tsx`) — no code change needed.

- `hero-loop.mp4` — the ~10–12s seamless loop, DAY → REGULATION → LETTING GO →
  PREPARATION → NIGHT → (loops back to DAY). Muted, autoplaying, so no audio
  is required in the export.
- `hero-loop-poster.jpg` (optional) — a still frame shown before the video
  loads.

## Brief this fulfills

Same character in all 5 scenes (~40–45yo European woman, natural look,
medium brown/dark-blonde hair, minimal makeup, premium cream linen blouse):

1. Active Day — phone face-down, pause
2. Regulation — touches the Yintang point between the eyebrows
3. Letting Go — applies a roll-on to the wrist
4. Preparation — closes a linen curtain as evening arrives
5. Night / Regeneration — settles into a premium linen bed; final frame
   drifts back toward morning light so the loop is seamless

Aesthetic: quiet luxury — natural linen, travertine, warm wood, cream/beige/
taupe, realistic natural light. Explicitly avoid: yoga, lotus flowers,
candles, spa towels, meditation clichés, smiling influencers, clinical
settings, mystical glow, blue "moonlight" bedrooms, over-golden grading,
plastic AI skin, product-commercial styling, on-video text, distorted
hands/anatomy.
